## Overview

Sumu analyzes audio into hundreds of tracked sinusoidal partials and resynthesizes them with independent control over each partial's amplitude, frequency, and pan, enabling extreme timbral manipulation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Madrona Labs Sumu** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Partial Tracking** | Analyze audio into up to 512 tracked spectral partials |
| **Additive Resynthesis** | Control amplitude, frequency, and pan per partial group |
| **Spectral Warp** | Stretch, compress, and shift the partial spectrum in real time |
| **MPE Support** | MIDI Polyphonic Expression for per-note spectral control |
